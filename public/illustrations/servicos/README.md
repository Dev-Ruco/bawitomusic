# Biblioteca de ilustrações de serviços

Dez ilustrações SVG independentes, desenvolvidas para os cartões de serviços da Bawito. A mesma paleta institucional é utilizada em todos os ficheiros: azuis #0A89CB e #174A86, sombras leves e fundos claros. Cada SVG é responsivo, contém apenas elementos vectoriais e não utiliza recursos externos. O texto dos serviços permanece no HTML para acessibilidade e indexação.
