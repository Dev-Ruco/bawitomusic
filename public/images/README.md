# Biblioteca de imagens — Bawito Music & Serviços

Esta pasta centraliza os recursos visuais utilizados no website.

## Organização

- `hero/`: imagens principais da página inicial (desktop e mobile).
- `servicos/`: imagens de cada serviço (som, iluminação, palcos, LED, streaming, etc.).
- `projectos/`: fotografias de eventos e trabalhos realizados.
- `equipa/`: fotografias de colaboradores, operação técnica e bastidores.
- `marca/`: logótipos oficiais e outros recursos gráficos da empresa.

## Regras de preparação

- Preferir WebP ou AVIF para fotografias; usar SVG ou PNG transparente para logótipos conforme necessário.
- Preparar versões para ecrãs pequenos e grandes sempre que a imagem seja importante, sobretudo no Hero.
- Utilizar nomes curtos, minúsculos, sem espaços nem acentos (ex.: `hero-conferencia-bawito-1280.webp`).
- Evitar ficheiros originais excessivamente pesados. Optimizar sem degradar visivelmente a imagem.
- Utilizar apenas imagens próprias ou com autorização; identificar imagens sintéticas/ilustrativas como tal, sem as apresentar como fotografias de projectos realmente executados.
- Referenciar os ficheiros no código por caminhos como `/images/hero/hero-conferencia-bawito-1280.webp`.

Estas pastas contêm inicialmente ficheiros `.gitkeep` para que sejam visíveis no GitHub mesmo antes de receberem imagens.
